# GitHub Project Setup

Create a user-level GitHub Project named **AI Portfolio Roadmap**.

## Recommended views

### Board

Group by `Status`:

```text
Backlog
Ready
In progress
Review
Done
```

### Table

Show:

```text
Title
Repository
Priority
Work type
Target version
Status
```

### Roadmap

Use target dates for release and major documentation milestones.

## Recommended fields

- `Repository`: flagship repositories, ISP, local backlight dimming, academic collaborations
- `Priority`: Critical, High, Medium, Low
- `Work type`: Release, CI, Testing, Documentation, Security, Example, Profile
- `Target version`: semantic version or milestone
- `Status`: Backlog, Ready, In progress, Review, Done
