# Topics and Profile Pins

Use this checklist when applying repository topics and pinning the six flagship repositories on the GitHub profile.

## Pin order

1. `learn-ai-evaluation`
2. `ai-model-validation-framework`
3. `ai-architecture-stack`
4. `edge-ai-computer-vision-deployment`
5. `llm-rag-evaluation-governance`
6. `ai-computational-methods`

## Topic sets

The exact topic lists are maintained in [`PORTFOLIO-MATURITY-PLAN.md`](PORTFOLIO-MATURITY-PLAN.md).

## UI checklist

- Open each repository and select the settings icon next to **About**.
- Add the prepared topics.
- Save changes.
- Open the GitHub profile.
- Select **Customize your pins**.
- Select the six repositories above.
- Arrange them in the recommended order.
